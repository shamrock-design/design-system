# Empty states

One component (Phase 2: `<EmptyState>`), one copy formula. No more "Not yet instrumented" / "No detail yet" / "no runs" / "—" drift.

**Formula:** `No <things> yet.` + one sentence saying how they appear + (optional) one primary action.

| Situation | Pattern | Example |
|---|---|---|
| Nothing created yet | noun + how + CTA | "No workflows yet. Create your first workflow to generate test cases from documents." [Create workflow] |
| Feature not wired for this object | state the fact plainly | "Not instrumented yet. Runs will appear once this stage reports data." |
| Filter/search returned nothing | echo the query + reset | "No jobs match 'MDMR'. Clear the search to see all 104 jobs." [Clear search] |
| Cell-level absence | `—` (em dash), `pending` styling | — |

Rules: sentence case, period at end, no exclamation marks, no "Oops". Illustration from `@shamrock-design/assets/illustrations/empty-states/` (optional, small). Never leave a bare region — absence is information.
